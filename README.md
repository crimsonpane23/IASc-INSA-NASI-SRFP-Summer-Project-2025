## 📘 Overview  

This repository documents the work carried out as part of the **IASc-INSA-NASI Summer Research Fellowship Project (SRFP 2025)**.  
The project focused on exploring **machine learning models** and **simulation techniques** to analyze and interpret physical data.  

The primary objectives were:  
- To develop an understanding of regression-based prediction techniques.  
- To visualize and interpret data trends through **output plots**.  
- To document results, findings, and analysis in structured reports.

## 🧠 Methodology (Brief Overview)

Although this repository primarily contains results and reports, the project combined two main components:

1. **Machine Learning Regression Studies:**  
   Comparative analysis of different regression models to predict target quantities from experimental data:
   1. Artificial Neural Network (MSE Loss)
   2. Artificial Neural Network (Logcosh Loss)
   3. Random Forest Regressor
   4. XGBoost Regressor

3. **GEANT4 Simulations:**  
   Basic detector simulations were performed using the GEANT4 toolkit to study detector construction. Rutherford Scattering was simulated, and the experimental result of Geiger and Marsden was verified.
---

## 📈 Results  

- The **machine learning models** demonstrated strong predictive capability for the given dataset.  
- The **simulation outputs** validated the capabilities of GEANT4 in modeling detectors  
- Representative visualizations and graphs are included in the *Model Prediction Plots* folder.
